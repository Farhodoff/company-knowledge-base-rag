Engineering Design

End-to-End System Architecture

Modular, decoupled architecture optimized for privacy, high retrieval accuracy, and zero hallucinations.

01

Multi-Format Ingestion

Recursively loads PDF handbooks, Markdown policies, CSV records, and TXT guides. Extracts page-level metadata and line offsets.

src/document_loader.py
02

Recursive Character Chunking

Splits text using semantic boundaries (paragraphs, headings, newlines) with 500-char window and 50-char overlap to maintain context coherence.

src/chunker.py
03

Dense Vector Store (FAISS)

Generates 768-dimensional embeddings using Google's text-embedding-004. Serializes index into fast local FAISS binaries for offline retrieval.

src/vectorstore.py
04

Grounded LCEL Chain

LangChain Expression Language pipeline binds retrieved documents into strict system prompt guardrails. If context is missing, the LLM refuses to invent answers.

src/chain.py
Rigor & Accuracy

Why Naive LLMs Fail at Company Docs

Direct LLM prompts hallucinate outdated public policies. Grounded RAG restricts generation strictly to internal facts.

macOS & Developer Tooling

Designed for Engineers on macOS

Run queries from your terminal without opening a browser, launch the native macOS Desktop application, or run the local Streamlit dashboard.

zsh — One-Line macOS Installer 
# Paste this one-liner into your macOS Terminal:
$ curl -fsSL https://raw.githubusercontent.com/Farhodoff/company-knowledge-base-rag/main/install.sh | bash

# The script automatically:
  [1/4] Clones repository to ~/.company-rag
  [2/4] Creates isolated Python virtual environment
  [3/4] Symlinks global CLI executable: ~/.local/bin/company-rag
  [4/4] Compiles native macOS desktop launcher: ~/Applications/Company Knowledge Base.app
  ✓ Installation complete! Type 'company-rag' to begin.
