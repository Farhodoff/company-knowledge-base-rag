System Design

End-to-End RAG Architecture

Designed with separation of concerns: automated multi-format ingestion, FAISS vector index, and anti-hallucination LCEL chains.

📥

Multi-Format Ingestion

Parses PDF, Markdown, TXT, DOCX, and CSV files recursively. Preserves metadata including page numbers, file sizes, and chunk indices.

🧠

Gemini & FAISS

Generates high-density embeddings via models/text-embedding-004 and stores them in local FAISS vector index files for sub-millisecond retrieval.

🛡️

Strict Anti-Hallucination

System prompts enforce strict grounding. If the answer is not in the company files, the assistant explicitly states it cannot find it.

macOS & Terminal Setup

Install Directly on macOS

Run as a global terminal CLI utility or native macOS Desktop application.

Terminal — One-Line Auto Installer 
# Run in your macOS terminal:
curl -fsSL https://raw.githubusercontent.com/Farhodoff/company-knowledge-base-rag/main/install.sh | bash

# What this installer does:
# 1. Sets up ~/.company-rag with isolated virtual environment
# 2. Creates global 'company-rag' CLI in ~/.local/bin
# 3. Builds native 'Company Knowledge Base.app' in ~/Applications
# 4. Indexes default sample documents automatically!
