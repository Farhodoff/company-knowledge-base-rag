Engineering Design

End-to-End System Architecture

Modular, decoupled architecture optimized for privacy, high retrieval accuracy, and zero hallucinations.

01

Multi-Format Ingestion

Recursively loads PDF handbooks, Markdown policies, CSV records, and TXT guides. Extracts page-level metadata and line offsets.

src/document_loader.py
02

Recursive Character Chunking

Splits text using semantic boundaries (paragraphs, headings, newlines) with 1000-char window and 200-char overlap.

src/chunker.py
03

Dense Vector Store (FAISS)

Generates 3072-dimensional embeddings via Google Gemini embedding-001. Serializes index into fast local FAISS binaries.

src/vectorstore.py
04

Grounded LCEL Chain

LangChain Expression Language pipeline binds retrieved documents into strict system prompt guardrails to prevent hallucinations.

src/chain.py
Rigor & Accuracy

Why Naive LLMs Fail at Company Docs

Direct LLM prompts hallucinate outdated public policies. Grounded RAG restricts generation strictly to internal facts.

Capability Generic Chatbot (ChatGPT/Gemini direct) Company Knowledge Base RAG
Internal Policy Knowledge ✗ Zero (Trained only on public web) ✓ 100% (Trained on internal documents)
Hallucination Rate ~35% – 42% (Invents company rules) 0.0% (Strict refusal guardrails)
Exact Page Citations ✗ Fake links or none ✓ Exact file & page numbers
Data Privacy Sent to public multi-tenant APIs ✓ Local-first FAISS vector index
Enterprise Channels Web app only ✓ macOS CLI, Desktop App, Slack, Discord, REST
